# NextZip 사용 설명서

NextZip은 Windows용 무료 압축 프로그램입니다. 광고·텔레메트리가 없고, 받은 압축 파일을 안전하게 푸는 데 신경을 썼습니다.

## 설치와 제거

1. 설치 파일(`nextzip-setup-<버전>.exe`)을 실행합니다.
2. 설치하면 탐색기 오른쪽 클릭 메뉴에 **NextZip** 항목이 생기고 압축 파일을 더블클릭하면 NextZip이 열립니다.
3. 제거는 **설정 → 앱 → 설치된 앱 → NextZip → 제거**에서 합니다.

> 지금 배포 파일은 테스트용 자체 서명 인증서로 서명되어 있어 SmartScreen 경고가 나올 수 있습니다.

## 압축 풀기

**탐색기에서 바로 풀기**: 압축 파일을 오른쪽 클릭 → NextZip →

- **여기에 풀기**: 압축 파일과 같은 폴더에 풉니다.
- **폴더로 풀기**: 압축 파일 이름으로 폴더를 만들어 그 안에 풉니다.

**프로그램 창에서**: 압축 파일을 더블클릭하거나 창으로 끌어다 놓으면 안의 목록이 보입니다.
도구 모음의 **풀기**(Ctrl+E)로 원하는 폴더에 풀고, **테스트**로 풀지 않고 손상 여부만 확인합니다.

- 암호가 걸린 압축 파일은 암호를 묻습니다. 틀리면 다시 묻습니다.
- 옛 한국어·일본어·중국어 압축 파일의 이름 깨짐은 **코드페이지 자동 판별**로 대부분 바로잡힙니다.
  잘못 판별되면 상태 표시줄의 코드페이지 버튼에서 직접 고를 수 있습니다.
- 진행 창에서 일시 정지·취소할 수 있습니다. 취소하면 쓰다 만 파일은 지웁니다.

## 압축하기

파일·폴더를 선택 → 오른쪽 클릭 → NextZip → **압축…**, 또는 프로그램 창의 **압축**(Ctrl+N).

- 형식: ZIP(기본, 어디서나 열림), 7Z(더 작게), TAR.ZST(빠르고 작게), 그 밖에 TAR.GZ/XZ/BZ2/LZ4, ZIPX, ISO, 자동 풀림 EXE.
- 프로필(초고속·균형·고압축·최대)을 고르면 압축 수준은 알아서 정하고, 모든 논리 프로세서를 씁니다.
- 압축할 때 암호 걸기·분할·복구 레코드는 아직 창에서 고를 수 없습니다(후속 단계). 예전 방식(ZipCrypto)으로는 만들지 않습니다.

## 설정: 언어와 악성코드 검사

프로그램 창 오른쪽 위의 **톱니바퀴(설정)** 버튼을 누르면 메뉴가 나옵니다.

| 항목 | 설명 |
|---|---|
| 언어: Windows 설정 따르기 | 기본값. Windows 표시 언어가 한국어면 한국어, 그 밖에는 영어 |
| 한국어 / English | 언어를 고정합니다. NextZip을 다시 시작하면 모든 화면(탐색기 메뉴 포함)에 적용됩니다 |
| 풀기 전에 악성코드 검사 (Windows AMSI) | 기본 켜짐. 끄면 확인 창이 한 번 뜹니다 |

설정은 `%LOCALAPPDATA%\NextZip\settings.txt`에 저장되고 프로그램 창, 탐색기 메뉴, 명령줄 도구가 함께 씁니다.

### 악성코드 검사

켜져 있으면 압축 파일 안의 내용을 **디스크에 쓰기 전에** Windows 보안(또는 AMSI를 지원하는 백신)에 검사받습니다.

- 악성코드가 발견된 파일은 풀지 않습니다. 나머지 파일은 풀고, 경고 창에 발견된 파일 이름을 보여 줍니다.
  그런 압축 파일은 열지 않는 것이 좋습니다. 자세한 내용은 **Windows 보안 → 바이러스 및 위협 방지 → 보호 기록**에 있습니다.
- 백신이 AMSI를 지원하지 않거나 정책으로 꺼져 있으면 "악성코드 검사 없이 풉니다"라는 알림이 뜨고 그대로 풉니다.
- 검사 때문에 풀기가 조금 느려질 수 있습니다. 믿을 수 있는 큰 압축 파일을 자주 푼다면 꺼도 됩니다.
  꺼도 Windows 보안의 실시간 보호는 그대로 동작합니다.

## 안전 장치

받은 압축 파일은 누가 만들었는지 모르므로 NextZip은 다음을 지킵니다.

- **폴더 밖으로 쓰지 않음**: `..\`·절대 경로가 들어 있는 압축 파일은 통째로 거부합니다. `CON`·`NUL` 같은 Windows 예약어는 앞에 `_`를 붙여 풀고, 이름을 바꾼 항목이 있으면 진행 창에 몇 개인지 알려 줍니다.
- **링크로 빠져나가지 못함**: 풀 폴더 밖을 가리키는 링크는 만들지 않습니다.
- **링크는 텍스트 파일로**: tar·RAR·LHA 등의 링크는 기본으로 "링크 대상 경로를 적은 작은 텍스트 파일"로 풉니다. tar 계열에서 실제 링크가 필요하면 설정 메뉴의 "tar의 심볼릭 링크를 실제 링크로 풀기"를 켜세요(CLI는 `-symlinks`). Windows에서 실제 링크를 만들려면 개발자 모드나 관리자 권한이 필요합니다.
- **압축 폭탄 차단**: 풀린 크기가 비정상적으로 크거나(압축 파일의 4096배 + 1 GiB 초과), 항목 수가 너무 많거나(압축 파일 바이트 수 + 1만 개 초과), ZIP 항목이 서로 겹치면 "압축 폭탄 의심"으로 멈춥니다.
- **격리 디코더**: RAR과 오래된·희귀한 형식은 권한을 거의 다 뺀 별도 프로세스(`nz-decode.exe`)에서 읽습니다. 이 프로세스는 파일을 쓸 수도, 다른 프로그램을 실행할 수도 없습니다. 너무 오래 걸리거나 메모리를 많이 쓰면 "손상된 압축 파일"로 중단됩니다.
- **인터넷 표시 유지**: 인터넷에서 받은 압축 파일을 풀면 푼 파일에도 "인터넷에서 받음" 표시(Mark of the Web)를 붙입니다. 그래서 푼 실행 파일·문서를 열 때도 Windows와 Office의 경고가 그대로 나옵니다.

## 자주 묻는 질문

**"압축 폭탄 의심"이 떴어요.** 정상 파일이 이렇게 걸리는 경우는 드뭅니다(같은 내용이 아주 많이 반복된 파일 정도). 출처를 믿을 수 있다면 다른 도구로 풀어 보고, 그렇지 않다면 지우세요.

**"악성코드가 발견되어 … 풀지 않았습니다".** Windows 보안이 그 파일을 악성으로 판단했습니다. 압축 파일째 지우는 것을 권합니다. 오탐이라고 확신하면 설정에서 검사를 끄고 풀 수 있지만, Windows 보안의 실시간 보호가 다시 막을 수 있습니다.

**"손상된 압축 파일: 디코더가 시간·메모리 한도를 넘어 중단했습니다".** 파일이 망가졌거나 일부러 디코더를 멈추게 만든 파일입니다. 다시 받아 보세요.

**이름이 깨져 보여요.** 상태 표시줄의 코드페이지 버튼에서 한국어(949)·일본어(932)·중국어(936/950)를 직접 골라 보세요.

**영어로 쓰고 싶어요.** 설정 → English를 고르고 NextZip을 다시 시작하세요.
