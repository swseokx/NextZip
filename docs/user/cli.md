# 명령줄 도구 `nz`

설치 폴더에 `nz.exe`가 있습니다. 전체 옵션은 `nz help`로 볼 수 있습니다. 도움말 자체는 영어입니다.

## 풀기와 목록

```
nz x [-o:<폴더>] [-p:<암호>] [-cp:<코드페이지>] [-t:N] [-noscan] [-symlinks] <압축 파일>
nz l [-p:<암호>] [-cp:<코드페이지>] [-json] <압축 파일>
```

| 옵션 | 설명 |
|---|---|
| `-o:<폴더>` | 풀 폴더 (기본: 압축 파일 이름에서 확장자를 뺀 폴더) |
| `-p:<암호>` | 암호. 명령줄 기록에 남으니 공용 PC에서는 조심하세요 |
| `-cp:<코드페이지>` | 옛 압축 파일 이름의 코드페이지 지정: 949, 932, 936, 950, 437, 866, 1252, utf8 |
| `-t:N` | 스레드 수 |
| `-noscan` | 이번에는 악성코드 검사(AMSI)를 하지 않음 |
| `-scan` | 설정에서 꺼 두었어도 이번에는 검사 |
| `-symlinks` | tar 계열의 심볼릭 링크를 실제 링크로 만듦 (기본: 링크 대상 경로를 담은 텍스트 파일) |
| `-json` | (`nz l`) 목록을 JSON으로 출력 |

악성코드가 발견되면 해당 파일은 쓰지 않고, 오류 메시지에 파일 이름을 보여 주며 종료 코드 1로 끝납니다.

## 압축하기

```
nz c [-fmt:<형식>] [-l:0..9] [-t:N] <만들 파일> <원본>...
```

형식은 `zip`, `7z`, `tar`, `tar.gz`, `tar.xz`, `tar.bz2`, `tar.lz4`, `tar.zst`, `zipx`, `iso`, `exe`(자동 풀림) 등입니다.
`-fmt`를 생략하면 만들 파일의 확장자로 정합니다.

## 언어

```
nz -lang:en x 파일.zip
nz x -lang:ko 파일.zip
```

`-lang:<ko|en|auto>`는 압축 라이브러리가 내는 메시지(오류 등)의 언어입니다. 지정하지 않으면
환경 변수 `NZ_LANG`, 설정 파일의 언어, Windows 표시 언어 순서로 정합니다.

## 환경 변수

| 변수 | 설명 |
|---|---|
| `NZ_LANG=ko` / `en` | 메시지 언어 |
| `NZ_SETTINGS=<파일>` | 설정 파일 위치 (기본 `%LOCALAPPDATA%\NextZip\settings.txt`) |
| `NZ_MEM_MIB=N` | 압축 메모리 예산(MiB). 결과물은 같고 작업 배치만 달라집니다 |
