손상에도 강한 압축 프로그램 A fast Windows archiver that opens almost anything and survives damage

NextZip은 엔진부터 GUI까지 Rust로 새로 만든 Windows용 압축 프로그램입니다. 모든 CPU 코어를 끝까지 쓰고, 받은 압축 파일은 격리된 프로세스에서 안전하게 엽니다. 광고도 텔레메트리도 없습니다. NextZip is a Windows archiver written from scratch in Rust, from the engine to the GUI. It uses every CPU core, opens downloaded archives in an isolated process, and has no ads and no telemetry.

받은 압축 파일을 안전하게Safe with downloaded archives

압축 파일은 누가 만들었는지 모른다는 전제로 설계했습니다. Designed on the assumption that you don’t know who made the archive.

격리 디코더Isolated decoder

RAR과 오래된·희귀한 형식은 별도 프로세스에서 읽습니다. Low integrity, 권한 제거, Job 개체, 메모리·시간 상한으로 파일을 쓰거나 다른 프로그램을 실행할 수 없습니다.

RAR and old or rare formats are parsed in a separate process with low integrity, stripped privileges, a job object and memory and time limits. It cannot write files or start programs.

AMSI 악성코드 검사AMSI malware scan

압축 파일 안의 내용을 디스크에 쓰기 전에 Windows 보안(또는 AMSI 지원 백신)으로 검사하고, 걸린 파일은 쓰지 않습니다.

Contents are scanned with Windows Security (or any AMSI-aware antivirus) before they touch the disk. Flagged files are never written.

Mark-of-the-Web

인터넷에서 받은 압축 파일을 풀면 푼 파일에도 “인터넷에서 받음” 표시를 붙여 Windows·Office 경고가 그대로 동작합니다.

Files extracted from a downloaded archive keep the “downloaded from the internet” mark, so Windows and Office warnings still work.

압축 폭탄 차단Bomb protection

풀린 크기, 항목 수, 겹치는 ZIP 항목을 검사해 압축 폭탄을 멈춥니다.

Expanded size, entry count and overlapping ZIP entries are checked to stop decompression bombs.

경로 탈출 차단Path traversal blocked

..·절대 경로·드라이브 문자가 든 아카이브는 거부하고, 출력 폴더 밖을 가리키는 링크는 만들지 않습니다.

Archives with .., absolute paths or drive letters are rejected, and links pointing outside the output folder are never created.

메모리 안전성Memory safety

엔진과 CLI는 unsafe_code = forbid. 리더마다 퍼징 타깃이 있고, 찾은 입력은 회귀 테스트로 남깁니다.

The engine and CLI use unsafe_code = forbid. Every reader has a fuzz target, and every finding becomes a regression test.

명령줄 빠른 시작CLI quick start

설치하면 nz 명령줄 도구가 함께 들어 있습니다. 형식은 확장자로 정해지고, 풀 때는 자동으로 판별합니다. The installer includes the nz command-line tool. The output format follows the file extension; input formats are detected automatically. 

nz c archive.7z .\project            # compress (format from extension)
nz c -fmt:zip -l:9 out.zip .\docs    # choose format and level
nz x -o:.\out archive.rar            # extract (format auto-detected)
nz l archive.zip                     # list contents
nz t archive.nz                      # test .nz (recovery record + all blocks)
nz backup daily.nz .\work            # incremental .nz backup
nz bench .\data -cases:zip:5,7z:6    # benchmark
