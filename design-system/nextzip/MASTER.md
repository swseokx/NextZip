# NextZip 디자인 시스템 (MASTER)

> 화면별 규칙은 `design-system/nextzip/pages/<화면>.md`가 있으면 그 파일이 우선합니다. 없으면 이 문서를 따릅니다.
> 토큰 원본: `tokens.css` (라이트·다크). 목업: `design/mockups/index.html`.

- 대상: Windows 10/11 데스크톱 앱. 구현은 Win32 + Direct2D(windows-rs), M2 단계
- 방향: Minimalism & Swiss Style. 기능 중심, 높은 대비, 장식 없음
- 다이얼: Variance 3 (차분), Motion 2 (미세), Density 8 (조밀, 파일 목록 중심)
- 원칙: **광고·웹뷰가 없는 빠른 도구.** 화면은 "파일 목록 + 할 일 버튼"만 보여 주고, 성능 정보(처리량, 스마트 처리 내역)는 진행 화면에서 정직하게 보여 줍니다.

---

## 1. 색상

생성기의 기본 팔레트(teal + orange, 민트 배경)를 데스크톱용으로 보정했습니다. 텍스트 대비가 부족한 조합(`#0D9488` 위 텍스트 3.74:1, 버튼 글자 검정)은 모두 교체했습니다. 대비 수치는 직접 계산해 확인했습니다.

- 색은 의미가 있을 때만 씁니다. 주 색은 화면당 주요 동작 하나(예: "압축 시작")와 진행 막대에만 씁니다.
- 상태는 색만으로 전달하지 않고 아이콘과 문구를 함께 씁니다(성공 ✓ 아이콘 + "완료").
- 시스템 고대비 모드(`forced-colors`)에서는 Windows 시스템 색을 그대로 따릅니다.
- 다크 모드는 Windows 앱 모드 설정을 따르고, 설정에서 직접 바꿀 수 있습니다.

## 2. 타이포그래피

웹 폰트를 쓰지 않습니다. 시스템 폰트를 써야 시작이 빠르고(K8) Windows 앱처럼 보입니다.

- 글꼴 순서: `Segoe UI Variable Text` → `Segoe UI` → `Malgun Gothic`(한글) → sans-serif
- 숫자 열(크기·압축률·처리량): `font-variant-numeric: tabular-nums`. 자릿수가 흔들리지 않아야 합니다.
- 경로·해시: `Cascadia Mono` → `Consolas`

| 단계 | 크기/줄높이 | 굵기 | 용도 |
|---|---|---|---|
| `--nz-type-title` | 20/28 | 600 | 대화상자 제목 |
| `--nz-type-subtitle` | 16/22 | 600 | 섹션 제목, 진행 화면의 핵심 수치 |
| `--nz-type-body` | 14/20 | 400 | 기본 텍스트, 버튼 |
| `--nz-type-caption` | 12/16 | 400 | 열 머리글, 상태바, 보조 설명(12px 미만 금지) |

## 3. 간격·크기·모양

- 간격 단위는 4px입니다: `2 · 4 · 8 · 12 · 16 · 24 · 32`
- 목록 행 높이: 기본 32px, 조밀 모드 28px. 행 안 좌우 여백은 12px입니다.
- 클릭 대상: 최소 32×32px(마우스 중심 데스크톱). 터치 모드를 켜면 40px로 키웁니다.
- 모서리: 컨트롤 4px, 카드·대화상자 8px. Windows 11 둥근 창 모서리와 맞춥니다.
- 그림자: 떠 있는 요소(메뉴·대화상자)에만 씁니다. 목록과 카드는 그림자 대신 1px 구분선을 씁니다.

## 4. 모션

- 상태 전환 120~150ms ease-out, 사라질 때는 더 빠르게(100ms).
- 진행 막대는 값 변화를 200ms로 보간합니다. 무한 애니메이션은 쓰지 않습니다.
- `prefers-reduced-motion`(Windows "애니메이션 효과" 끔)이면 모든 전환을 즉시 처리합니다.
- 금지: 호버 시 위로 떠오르는 효과, 스크롤 연출. 도구에는 필요 없습니다.

## 5. 아이콘

- Fluent System Icons(Regular 20px, 강조 Filled)만 씁니다. 이모지는 쓰지 않습니다.
- 아이콘만 있는 버튼에는 접근성 이름과 툴팁을 반드시 붙입니다.
- 파일 형식 아이콘은 Windows 셸 아이콘을 그대로 씁니다(사용자가 익숙한 모양).

## 6. 화면 구성 (정보 구조)

| 화면 | 구성 | 목업 |
|---|---|---|
| 메인 창 | 제목줄(Mica) → 툴바(압축·풀기·테스트·추가·삭제 / 보기) → 경로 막대 → [폴더 트리 \| 파일 목록 \| 미리보기 패널(접기 가능)] → 상태바(파일 수·원본 크기·압축 크기·포맷·암호화 여부) | ① |
| 빈 상태(시작 화면) | 끌어다 놓기 영역 + 최근 파일 + 단축키 안내. 광고 영역 없음 | ① 변형 |
| 압축 대화상자 | 필수 3개(파일명, 포맷, 프로필)만 기본 노출. 암호화·분할·복구 레코드·고급은 접힌 영역 | ② |
| 진행 창 | 전체 진행률, 처리량(MB/s), 남은 시간, 스마트 처리 내역("JAR 412개 그대로 저장"), 스레드 사용률 막대, 일시정지·취소·백그라운드 | ③ |
| 완료 알림 | 결과 요약(압축률, 걸린 시간을 절대 수치로만 표시, 타사 비교 문구 없음) + "폴더 열기" | ③ 하단 |

## 7. 컴포넌트 규칙

- **버튼:** 주 버튼(채움, `--nz-primary`)은 대화상자당 하나입니다. 나머지는 테두리 버튼, 툴바는 아이콘+글자 버튼입니다. 높이는 32px, 좌우 여백은 12px입니다.
- **파일 목록:** 가상화 목록(수십만 항목). 열은 이름 · 크기 · 압축 크기 · 압축률 · 수정한 날짜 · 방법 · CRC/해시입니다. 정렬 상태는 머리글 아이콘과 `aria-sort`로 표시합니다. 다중 선택은 Ctrl/Shift를 쓰고, 행 전체를 끌어다 놓을 수 있습니다.
- **포맷 선택:** 세그먼트 컨트롤로 자주 쓰는 4개(ZIP · 7Z · NZ · TAR.ZST)를 보여 주고, 나머지는 드롭다운에 둡니다. 선택한 포맷의 호환성을 한 줄로 안내합니다("ZIP: 모든 PC에서 열림").
- **압축 프로필:** 레벨 숫자 대신 초고속 · 균형 · 고압축 · 최대 · 호환을 고릅니다. 각각 예상 속도와 압축률 막대를 함께 보여 줍니다.
- **진행 막대:** 결정형만 씁니다. 전체 크기를 계산하는 동안에는 "파일 목록 확인 중 (1,204개)"처럼 셀 수 있는 문구를 보여 줍니다.
- **입력:** 레이블은 항상 보이게 둡니다. 오류는 필드 바로 아래에 표시합니다. 암호 입력에는 강도 표시와 보기 토글을 둡니다.
- **포커스:** 모든 상호작용 요소에 2px 포커스 링, 오프셋 2px를 둡니다. 탭 순서는 시각 순서와 같게 합니다. 주요 동작에는 액세스 키(Alt+밑줄 글자)를 둡니다.

## 8. 금지 사항

- 광고, 배너, 제휴 링크, 웹뷰 기반 화면
- 시작할 때 네트워크 호출 (업데이트 확인은 백그라운드에서, 끌 수 있게)
- 설치할 때 파일 연결을 강제로 바꾸기
- 12px 미만 텍스트, 회색 위 회색 텍스트, 색만으로 상태 전달
- 무한 스피너(남은 양을 셀 수 있는데도 쓰는 경우)
